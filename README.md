# 📈 Когортный анализ и LTV (Cohort & LTV Calculator)

**Когортный калькулятор** — это веб-инструмент для продуктовых и маркетинговых аналитиков, который позволяет загрузить сырые транзакции (CSV/Excel) и мгновенно рассчитать одну из самых важных бизнес-метрик — **LTV** и **Retention**. 

## 💡 Почему это полезно?
Вручную считать когорты и накопительный LTV в Excel или Pandas — это часы рутины и риск ошибок. Этот инструмент делает это за 2 секунды, автоматически находит аномалии (пустые периоды) и строит наглядную матрицу.

## 🚀 Ключевые возможности
1. **Загрузка данных:** Поддержка `.csv`, `.xlsx`, `.xls`. Автоматическое определение колонок (ID клиента, Дата, Выручка).
2. **Когортная матрица:** 
   - Группировка клиентов по месяцу их **первой** покупки.
   - Расчет удержания (%) по месяцам (Месяц 0, Месяц 1, ...).
3. **Расчет накопительного LTV:**
   - Корректный расчет кумулятивной выручки по когортам.
   - Обработка edge-cases: инструмент корректно показывает накопленный LTV даже в те месяцы, когда клиент не совершал покупок (не сбрасывает значение в ноль).
   - Взвешенное среднее LTV по всем когортам.
4. **Визуализация:** Цветовая шкала от темно-зеленого (высокое удержание) до красного (отток).
5. **Экспорт:** Выгрузка матрицы Retention и LTV в Excel (отдельные листы).

## 🛠 Стек технологий
- **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+).
- **Библиотеки:** SheetJS (парсинг Excel).
- **Логика:** Написание собственных алгоритмов агрегации и расчета дат без использования тяжелых бэкенд-фреймворков.

## 💻 Как запустить локально
1. Скачайте репозиторий.
2. Откройте файл `calculator.html` в любом современном браузере.
